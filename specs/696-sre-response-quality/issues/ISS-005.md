# ISS-005 — Quality Evolution is inline instead of a lateral overlay

status: RESOLVED
reported: 2026-10-20 by user
repository: soarplus-frontend-app1
touches_contract_or_spec: yes
triage: required

## Observation

The approved frontend plan and the implemented `/quality` page use a master-detail layout: selecting a catalog row renders the Evolution card inline below the catalog. The user now wants the same Evolution content to appear over the catalog in a right-side modal drawer, following the existing Radix `Dialog`/drawer presentation pattern used by Playbook editing. The requested change does not open or edit a Playbook.

Verified frontend evidence at commit `91f49bb9aa0e93d76164dab836d5330f400a8106`:

- `src/app/quality/page.tsx:59,103-113,165-227` owns `selected`, the dependent history query, and the inline Evolution card.
- `src/components/ui/quality-evolution-chart.tsx` and `quality-points-table.tsx` are presentational children and can render inside a dialog without API changes.
- `src/components/ui/dialog.tsx` provides the Radix dialog primitive.
- `src/components/playbooks/PlaybookEditorDrawer.tsx:67-110` demonstrates the right-side, full-height overlay pattern, but the component itself is coupled to Playbook form state and must not be reused as an Evolution container.

No code was changed during investigation.
