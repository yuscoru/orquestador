## Observation

The user needs an endpoint that queries **all targets** and returns, per target, the
**historical evaluations with their metrics by date** (rubrics and hallucinations).

Per the approved plan (plan.md §3), the surface is:
- R1 `GET /quality/targets` — catalog, **latest** valid point per target only;
- R2 `GET /quality/targets/{target_type}/{target}/evaluations` — history of **one** target.

No route returns history across all targets in one call. The user believes no such endpoint
exists; to be confirmed by triage against the implemented code.
